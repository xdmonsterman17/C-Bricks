# Reference plugin

`brickscript/` is a copy of **Brickscript**, a Godot editor plugin for visual scripting that C-Bricks grew out of: C-Bricks'
palette, canvas, Properties panel, exits that grow when wired, and problem messages follow its design. Brickscript itself was
never released; this copy is only here to read. None of its code is part of the C-Bricks editor or its output, and it is left
out of the exported editor.
